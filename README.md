# Proca-Yukawa-Field-Modulations-in-Molecular-Nano-Electronics
Hybrid Quantum-Classical simulation of sub-5nm molecular junctions using Proca-Yukawa field theory. This project implements a Variational Quantum Eigensolver (VQE) to analyze electronic phase-quenching and interference in non-Maxwellian electromagnetic environments. Optimized for IBM Quantum (Qiskit).
